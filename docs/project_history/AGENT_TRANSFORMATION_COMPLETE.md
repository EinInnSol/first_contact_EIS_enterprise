### **Code Generation**

**Before:**
- Generic code that works anywhere
- Manual secret management
- Basic error handling

**After:**
- GCP-optimized code
- IAM-based authentication (no secrets)
- Retry logic + structured logging built-in

**Example:**
```python
# Old (generic)
client = anthropic.Anthropic(api_key=os.getenv("ANTHROPIC_API_KEY"))

# New (GCP-native)
from anthropic import AnthropicVertex
client = AnthropicVertex(region="us-east5", project_id="your-project")
# No API key! Uses Application Default Credentials
```

### **Security**

**Before:**
- Secrets in environment variables
- Basic authentication
- Minimal audit logging

**After:**
- Secrets in Secret Manager (IAM-controlled)
- Firebase Auth or JWT with best practices
- Comprehensive Cloud Logging with structured data

**Example:**
```python
# Old
API_KEY = os.getenv("API_KEY")  # In .env file

# New
from google.cloud import secretmanager
api_key = get_secret("project-id", "api-key")  # From Secret Manager
# + IAM permissions required
# + Access logged to Cloud Logging
```

### **Deployment**

**Before:**
- Manual deployment steps
- Inconsistent configurations
- No monitoring setup

**After:**
- Automated workflow
- Consistent GCP-optimized config
- Monitoring + alerting by default

**Example:**
```bash
# Old
docker build -t api .
docker push ...
manual kubectl apply ...

# New
gcloud run deploy api --source=. \
  --set-secrets=JWT_SECRET=jwt-secret:latest \
  --add-cloudsql-instances=PROJECT:REGION:INSTANCE \
  --min-instances=0 --max-instances=10
# + Health checks configured
# + Monitoring dashboard created
# + Alert policies set up
```
