# 🎯 First Contact E.I.S. - Interactive Demo Wizard

## ✨ What Is This?

A **standalone, fully functional demo** that showcases all First Contact E.I.S. innovations in a guided, step-by-step wizard. No setup, no database, no authentication required!

---

## 🚀 Quick Start

### Local Demo

**Windows:**
```bash
START_DEMO_WIZARD.bat
```

**Mac/Linux:**
```bash
cd frontend
npm install
npm run dev
```

Then visit: **http://localhost:3000/demo**

---

## 🌐 Deploy to Cloud

### Vercel (Easiest - 2 minutes)

```bash
cd frontend
npm install -g vercel
vercel
```

### Netlify

```bash
cd frontend
npm install -g netlify-cli
npm run build
netlify deploy --prod
```

### Google Cloud Run

```bash
cd frontend
gcloud run deploy firstcontact-demo \
  --source . \
  --platform managed \
  --region us-central1 \
  --allow-unauthenticated
```

See [DEMO_DEPLOYMENT.md](./DEMO_DEPLOYMENT.md) for detailed instructions.
